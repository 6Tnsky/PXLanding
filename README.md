# Параграfикс — лендинг

Статический лендинг сервиса «Параграfикс»: ребёнок читает параграф и отвечает на 15 вопросов в Telegram или MAX, родителю приходит короткий итог — тема понята или какие вопросы стоит обсудить.

## Структура

- `index.html` — разметка страницы
- `style.css` — стили
- `app.js` — динамика: сборка экранов телефонов, FAQ, анимации (GSAP + ScrollTrigger)
- `assets/` — логотип, фавикон и фотографии (webp)

## Локальный запуск

Сборка не нужна — достаточно открыть `index.html` в браузере.
Либо поднять статический сервер из корня проекта:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Деплой

GitHub Pages: ветка `main`, корень репозитория (`/ (root)`).

Адрес сайта: https://6tnsky.github.io/PXLanding/

## Внешние зависимости (CDN)

- GSAP 3.12.5 + ScrollTrigger — jsdelivr
- Lucide 0.460.0 — unpkg
- Шрифт Onest — Google Fonts

## Примечания

- Все пути в разметке относительные (`./style.css`, `./assets/...`) — страница корректно работает и в корне домена, и в подпапке `/PXLanding/`.
- Файл `.nojekyll` отключает обработку через Jekyll, чтобы GitHub Pages отдавал файлы как есть.
